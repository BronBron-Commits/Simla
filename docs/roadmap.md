# Simla Roadmap

This is a lightweight project roadmap for contributors who want to understand where the repo is heading.

## Near-Term

* onboarding improvements
* runtime stability and parity verification
* mobile support for key demos
* deterministic replay tooling

## Mid-Term

* ECS runtime systems
* networking experiments
* stronger developer tooling
* asset pipeline cleanup

## Long-Term

* self-hosting compiler work
* standalone runtime packaging
* multiplayer simulation support

## Good First Contribution Areas

* README fixes and onboarding polish
* demo stability and browser cleanup
* focused tests for parser, compiler, and VM behavior
* documentation improvements
